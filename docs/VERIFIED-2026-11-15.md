## 能开机的构建配方（关键结论）

之前多版内核"能编译、但一刷就卡在 MI 标志"。真因不是打包、不是 AVB、也不是 droidspaces 配置，而是：

> 厂商模块（`msm_drm.ko`、`fts_touch_spi.ko`、`xiaomi_touch.ko`、`apr_dlkm.ko`、`snd_event_dlkm.ko`、
> `q6_notifier_dlkm.ko` …）是 **CFI 编译**的，未定义符号里带 `__cfi_slowpath`。
> 该符号只在 `CONFIG_CFI_CLANG=y` 时由 `kernel/cfi.c` 导出；内核一旦关掉 CFI，
> 显示/触摸等模块全部加载失败 → 内核已启动但 userspace 卡死。

因此必须同时满足：

| 项 | 值 |
| --- | --- |
| 编译器 | **AOSP prebuilt clang**（本次 `clang-r547379`，clang 20.0.0），不能用发行版 clang |
| 配置 | 设备原厂配置原样：`CONFIG_LTO_CLANG=y`、`CONFIG_CFI_CLANG=y`、`CONFIG_SHADOW_CALL_STACK=y` |
| 额外 CFLAGS | `-D__ANDROID_COMMON_KERNEL__`（LineageOS `build.config.common` 同样会传） |
| 版本串 | `LOCALVERSION="-qgki-g7ede20c8692e"`，且不能带 dirty 的 `+`（工作树有改动时要处理 `scripts/setlocalversion`） |
| droidspaces | `config/droidspaces-gki.config` + `patches/001_sysvipc_venus.patch`、`002_posix_mqueue_venus.patch` |

源码固定：`LineageOS/android_kernel_xiaomi_sm8350` @ `7ede20c8692e0e0fc044754429e33cfd1d75c40d`。

完整构建见 [`.github/workflows/build-kernel.yml`](../.github/workflows/build-kernel.yml)（workflow v8）。

## 已知限制

- `--cpus`（`CONFIG_CFS_BANDWIDTH`）与 `--pids-limit`（`CONFIG_CGROUP_PIDS`）未启用：
  这两个选项会改变调度器/cgroup 结构体大小，破坏 kABI，导致厂商模块拒绝加载。
- 与 ROM 强绑定：仅适用于 LineageOS 23.2 `20261104`（kernel commit `7ede20c8`）。
- 测试机为 M2011K2C（国行 venus），解锁 bootloader。
